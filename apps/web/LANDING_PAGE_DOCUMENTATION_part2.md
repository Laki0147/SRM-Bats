Known Issues & Solutions

### Issue: Framer Motion SSR Warnings

**Solution:** All animated components use `'use client'` directive

### Issue: Font Loading Flash

**Solution:** Fonts use `display: 'swap'` and are preloaded

### Issue: Mobile Menu Scroll Lock

**Solution:** Implement body scroll lock when menu is open (if needed)
